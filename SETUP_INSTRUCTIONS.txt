Follow these 3 simple steps to run CodeWeaver AI on your local machine:


═══════════════════════════════════════════════════════════════════════════════
STEP 1: GET YOUR API KEY (Free)
═══════════════════════════════════════════════════════════════════════════════

  1. Go to: https://aistudio.google.com/app/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Copy the key (you'll paste it in the app)


═══════════════════════════════════════════════════════════════════════════════
STEP 2: INSTALL DEPENDENCIES
═══════════════════════════════════════════════════════════════════════════════

  WINDOWS:
  ────────
  > run setup_venv.bat

  or manually:
  > python -m venv venv
  > .\venv\Scripts\activate
  > pip install -r requirements.txt


  LINUX/MAC:
  ──────────
  $ python3 -m venv venv
  $ source venv/bin/activate
  $ pip install -r requirements.txt


═══════════════════════════════════════════════════════════════════════════════
STEP 3: RUN THE APP
═══════════════════════════════════════════════════════════════════════════════

  WINDOWS:
  ────────
  > run_app.bat

  LINUX/MAC:
  ──────────
  $ chmod +x run_app.sh
  $ ./run_app.sh

  or directly:
  $ streamlit run main.py


═══════════════════════════════════════════════════════════════════════════════
OPEN IN BROWSER
═══════════════════════════════════════════════════════════════════════════════

  Navigate to: http://localhost:8501
  Paste your API key in the sidebar → Click "Connect" → Start coding!
